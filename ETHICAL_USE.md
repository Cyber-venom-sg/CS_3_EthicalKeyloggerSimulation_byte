# Ethical Use Declaration

This project is created strictly for educational and internship purposes.

The program does not perform hidden or unauthorized keylogging.
It only records test input that is manually entered into the program by the user.

The encrypted log is stored locally for demonstration purposes.

I understand that keylogging can be used to monitor sensitive information without permission. Therefore, this project must not be used to monitor, capture, or record another person's keystrokes without explicit authorization.

I will use this project only on my own device or in an authorized testing environment.

## Privacy and Security

- No real passwords or sensitive information should be entered.
- Test data is stored locally.
- Log data is encrypted before being saved.
- The project is intended only for cybersecurity education and ethical testing.

**Declaration:**  
I confirm that this project is intended for authorized and educational use only.
